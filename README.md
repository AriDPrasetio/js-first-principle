# JavaScript Fundamentals — with AGY

Repositori ini digunakan untuk mempelajari dan mempraktikkan dasar-dasar JavaScript secara bertahap, khusus dalam scope _Frontend Developer_, sebagai fondasi kokoh sebelum masuk ke ekosistem React.

## 📁 Struktur Proyek

- [`.agents/instructions.md`](./.agents/instructions.md): Panduan peran agent, aturan sumber resmi (MDN, web.dev, WHATWG), dan format output First Principles.
- [`.agents/roadmap.md`](./.agents/roadmap.md): Roadmap kurikulum lengkap dengan tracking status pembelajaran.

---

## 🎯 Aturan Riset & Catatan

1. **Sumber Wajib Resmi:** MDN Web Docs, web.dev, W3C/WHATWG.
2. **Format Standar Obsidian:** Dilengkapi YAML frontmatter, Ringkasan Konsep, Kenapa Penting, Detail & Syntax, Pitfalls, `[[wikilinks]]`, Active Recall questions, dan Sumber persis.
3. **Praktis & Ringkas:** Dirancang agar bisa dipahami dan diketik ulang tangan dalam <15 menit per topik.
