# JavaScript Fundamentals — Learning Roadmap

Repositori ini digunakan untuk mempelajari dan mempraktikkan dasar-dasar JavaScript secara bertahap dari nol, sebagai fondasi kokoh sebelum masuk ke React.

Setiap topik menyediakan dua versi panduan:

- **🌱 Pemula**: Analogi nyata, kode minimal interaktif HTML+JS, komentar terjemahan manusiawi, dan latihan aktif.
- **🔬 Deep Dive**: Analisis First Principles mendalam berakar pada spesifikasi ECMA-262 dan WHATWG.
